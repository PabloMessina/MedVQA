# ==============================================================================
# mediastinal_shift
# Explicit shift / deviation / displacement / push / pull of mediastinum, heart,
# or cardiomediastinal silhouette/contour. Trachea alone is omitted (prompt:
# tracheal deviation supports only when mediastinal displacement is also
# stated). Do not infer from widening / mass / effusion / atelectasis.
#
# Gaps are clause-local ([^\w.!?;:]) to avoid cross-sentence FPs.
# Stdlib re lookbehinds are fixed-width: enumerate modifier/list negations.
# Section 5 drops project* (gas "projecting to the right" is not displacement).
# pull/drawn: anatomy + toward/to OR leftward/rightward (not bare tube "pulled back").
# FN-fit w19: migrat* on mediastinal/heart arms only (not lead/stent/wire);
# agentive moving|pushing|pulling the mediastinum/heart (not trachea-only).
# FN-fit hunt: compact cardiac shift; shift of midline structures (verb-first only,
# not anatomy-first — head-CT "Midline structures are shifted"); off the midline;
# copula remains/stays; pulled leftward without to|toward.
# ==============================================================================

# Shared fragments (expanded inline; stdlib re has no defines):
#   ANATOMY: mediastinum / mediastinal(?! fat) | heart | cardiac silhouette |
#            cardiomediastinal…
#   SHIFT:   shift\w* | hift\w* | shoft\w* | deviat\w* | displac\w* | push\w*
#            | migrat\w* (compact / direction-first / verb…anatomy / has-migrated)
#            | pull(?:ed|ing) | drawn  (pull/drawn: anatomy+toward|ward)
#            | moving|pushing|pulling the mediastinum (agentive arm)
#            | cardiac shift (compact); shift of midline structures (verb-first)

# ------------------------------------------------------------------------------
