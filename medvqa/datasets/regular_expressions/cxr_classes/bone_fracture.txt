# Dedicated arms start at `known` / `previously noted` so those lookbehinds
# do not block currently visible mentions; keep history/indication guards.
# Walks: median/wing/blade/about/along; 2f `from`; 2g cannot-exclude;
# 2h cortical disruption; hyphen `fractured-appearing`; chronic-changes /
# dysmorphic sequela framed with fracture. Do not copy rib/clavicle/VCF.
# Do NOT merge helper bare deform* / dislocat* or callus_rib.
# Do NOT infer from wedging/collapse, DJD, hardware, or broken devices.
# Do NOT match: bare deformity; history/indication-only; negation; degenerative
# change / osteopenia / scoliosis / lytic lesions; sternotomy / osteotomy /
# hardware without stated fracture; fractured devices / leads / wires / catheters.
