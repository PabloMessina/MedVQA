# mediastinal_mass
# Focal mediastinal soft-tissue opacity / contour abnormality framed as a mass
# or mass-like lesion on the current CXR.
#
# Match: mediastinal mass / mass-like / tumor; intervening soft[- ]tissue;
# mass in/within (compartment incl. mid/lower ranges) mediastinum;
# mass-like opacity|density in mediastinum; mass projecting into mediastinum;
# cervicomediastinal mass; mediastinal lesion ... mass; mass behind the heart;
# lesion in the (anterior) mediastinum; station-scoped mass lesion not excluded;
# nodal / conglomerate / adenopathy/mass; paratracheal / prevascular /
# retrosternal soft[- ]tissue mass; mediastinal[/and]hilar mass;
# AP / aortopulmonary window mass (noun-order, region-of, is-seen);
# mass arising from the mediastinum; mass in the anterior clear space.
#
# Compartment adjectives (anterior/…) are a separate arm so history/resection
# lookbehinds apply at the adjective, not after it (bare arm also refuses to
# start at "mediastinal" when a compartment adjective immediately precedes).
#
# Do NOT match: history / indication / evaluate-for / post-op / resection-only;
# CT/prior-only ("seen on CT"); negated / "or … mediastinal mass" list tails;
# "limits detection of"; unconstrained "mass lesion is not excluded";
# nonspecific mediastinal opacity or bare contour bulge without mass framing;
# diffuse widening alone; adenopathy alone; thyroid mass / goiter alone;
# pulmonary/pleural/hilar mass alone; mere projection over mediastinum.
# ==============================================================================
