# ==============================================================================
# costophrenic_angle_blunting
# Direct CPA / sulcus / recess blunting language + location-specific fluid
# proxies. General pleural-effusion / hydrothorax inference intentionally
# omitted (prompt: do not infer blunting from effusion alone).
#
# Gap tokens use [^\w.!?;:] so matches stay within a clause/sentence after
# eval's whitespace normalization (newlines already collapsed to spaces).
# Negation: stacked fixed-width lookbehinds (stdlib re limitation).
#
# Notes vs prior production leaf:
# - sinuses? never matched singular "sinus" -> sinus(?:es)?
# - IU de-id often redacts angles/sulci as XXXX after costophrenic/CP
# - costo diaphragmatic (space) and indistinct/blur synonyms
# FN-fit hunt lexicon (wave 7):
# - gutter(s); bare CPA; costophrenic area/focus; bare costophrenic blunting;
#   loss of sulcus/angle; posterior gutter + obscuration of the angle
# FN-fit hunt lexicon (wave 28):
# - costrophrenic typo (cost(?:r?o)-?phrenic); angels typo for angles;
#   costophrenic sulcal blunting; bare costodiaphragmatic blunt* compound
# ==============================================================================
