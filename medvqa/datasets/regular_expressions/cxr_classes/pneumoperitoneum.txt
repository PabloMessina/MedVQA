# pneumoperitoneum
# Free gas in the peritoneal cavity on the current CXR.
#
# Match: pneumoperitoneum / aeroperitoneum; free intraperitoneal /
# peritoneal / intra-abdominal / abdominal air|gas;
# free air|gas under/below/beneath/(underneath) the (hemi)diaphragm;
# subdiaphragmatic / subphrenic / infradiaphragmatic air|gas;
# Rigler / double-wall / cupola sign (when present / attributed);
# extraluminal air|gas (abdomen / LUQ / under diaphragm).
#
# FN-fit (fn_mine_fit_shared / wave-33 hunt):
# - contrastive restart at although|though|however|but;
# - previous radiograph/exam comparison exception in tempered scan;
# - previously-seen PP / subphrenic|subdiaphragmatic air still present
#   (decrease / unchanged / less apparent);
# - extraluminal air|gas arm; diaphragm "aspects of" gap.
#
# Do NOT match: negated / resolved / resolution-of / not-seen / simulate;
# indication / rule-out / history-only "with pneumoperitoneum";
# pneumothorax / pneumomediastinum / subcutaneous emphysema alone;
# normal gastric bubble / Chilaiditi; CT-only / cannot-exclude extraluminal.
# ==============================================================================
