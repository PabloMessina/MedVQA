# lung_opacity (mid-node residual — precision-first)
# Umbrella: increased radiographic density within lung parenchyma.
# Ontology children (readonly) cover atelectasis/lobar/rounded, consolidation,
# pneumonia, edema, nodule/mass (+calcified), GGO, reticular interstitial,
# Kerley, fibrosis, focal scarring. Production OR-helpers (infiltration /
# alveolar_pattern / air_bronchogram / abscess / miliary_opacities) are
# invisible in hierarchy-aware eval — recover residual umbrella phrasing here.
#
# Prefer residual phrasing children miss: nonspecific opacity/opacification/
# density/shadowing; airspace/alveolar opacity/disease/process; infiltrate/
# infiltration; air bronchogram; miliary opacity/pattern; framed lung abscess;
# interstitial prominence/markings (when not child-covered).
#
# Phase B1: merge prompt-faithful helper residual only — discard bare
# alveolar\w*, bare abscess, bare infiltrat(ed|ing), indication-only, and
# diffuse-micronodule phrases already covered by nodule child.
#
# FN-fit (fn_mine_fit_shared): residual parent holes only — interval-change
# adjectives + plural; affirmative-only resolution lookahead; density hops
# (and/to/each/lateral/involving); markings mild/coarse/diffuse; interstitial
# lung / pulmonary insertions; markings-appear ADJ; increase-in markings;
# haziness/hazy (lung/RDS-framed); RDS granular density. Do not re-lexicon children.
#
# FN-fit pass-2 (approved hunt TPs): adj-first hazy lungs; opac* typos
# (opacitites/opacitiy/opacifcation); lung/lobe-framed infiltrated;
# granular appearance (not only densit*); interstitial accentuation;
# copula+dense (retrocardiac/lung); parenchymal lung disease; lobe is
# opaque; shadowing at; pulmonary clouding. Not: hemithorax white-out,
# perivascular haze, density overlying, bare lung markings, CXR attenuation.
#
# Do NOT re-implement child lexicons. Do NOT match: vascular congestion alone;
# pleural effusion / PTX / pneumomediastinum / SQ emphysema; support devices;
# extrapulmonary densities/artifacts (nipple/breast/cardiac shadow, sinus/
# contrast opacification); hyperlucency/emphysema; thin-walled cysts/bullae
# without opaque component; clinical/history/indication-only pneumonia.
#
# Clause-local tempered scan (pneumothorax / consolidation style).
# Fixed-width lookbehinds only. Compiled IGNORECASE|VERBOSE.
# ==============================================================================

    (?:

        (?<!contrast\s)

        (?<!rectal\scontrast\s)
        (?<!oral\scontrast\s)

        \bopac(?:it(?:y|ies|ites|iy)|ifi\w*|ifcation)\b

        (?!\s+(?:the\s+)?(?:stomach|bowel|colon|rectum|bladder|duodenum|small\s+bowel))

        (?![^.!?;:\n]{0,110}\b(?:

        (?<!mesenteric\s)
        (?<!soft\stissue\s)

        (?!\s+of\s+(?:the\s+)?(?:subcutaneous|fat|liver|hepatic|mesentery|soft\s+tissue))
        (?!\?)
        (?![^.!?;:\n]{0,100}\b(?:
            (?:has|have|is|are|was|were)\s+(?:(?:now|nearly|almost|completely|fully|entirely)\s+){0,2}(?:resolv\w*|cleared|clearing)|
            (?:is|are)\s+not\s+(?:seen|identified|present|evident)|

        # ==============================================================
        # 2b. Verb "infiltrated" with lung/lobe copula (not procedure/

        # ==============================================================

            (?:(?:right|left|both|bilateral|the)\s+)?(?:lung|lungs|lobe|lobes)\b
            \s+(?:is|are|appears?|remain(?:s|ed)?)\s+
            (?:(?:diffusely|mildly|slightly|moderately|markedly|completely|fully)\s+)?

            |

            (?:a\s+|an\s+|the\s+)?(?:(?:small|large|moderate|trace|layering|loculated)\s+)?(?:pleural\s+)?effusion\w*|
